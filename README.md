# LinguaLocal

Application web de traduction du français vers le bamoun.

## Objectif
Faciliter l'accès à la traduction et préserver la langue bamoun, malgré la rareté des ressources numériques.

## Fonctionnalités (MVP)
- Saisie d'un mot ou d'une phrase en français et traduction instantanée
- Gestion du dictionnaire (consultation, recherche, mise à jour)
- Message clair quand un mot est absent du lexique
